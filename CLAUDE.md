# Project Rules

## Read-Only Mode

- Do NOT update or modify any existing files in this repo
- Only provide observations and analysis
- If file output is needed, create new `.md` files only

## Scope

Focus only on these three sources:

| Source | Side | Format |
|--------|------|--------|
| `confdata_android.sql` | Client | SQL |
| `gameres_config_android/` | Client | Files/dirs |
| `prod_Config_S1/` | Server | Files/dirs |

## Objective

Observe and report config mismatches between client and server.
Output findings as new `.md` files with instructions to fix and sync configs.
